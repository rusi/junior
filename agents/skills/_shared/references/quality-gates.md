# Quality Gates

Apply these gates before marking work complete.

1. Scope gate
- Change set matches requested scope.
- Unrelated files are untouched.

2. Correctness gate
- Acceptance criteria are satisfied.
- Edge cases and error paths are considered.

3. Verification gate
- Relevant tests/checks run and pass.
- If checks cannot run, explain why and provide manual verification steps.

4. Documentation gate
- Specs/checklists/status files are updated with evidence.
- References and links remain valid.

5. Handoff gate
- Summarize outcome, evidence, residual risks, and next action.
