# Viewing the walkthrough

Open the walkthrough's `index.html` in a browser. Keep the entire directory together;
images and recordings load from relative paths and require no server or account.

Select an image to open the full panel. Use Previous and Next, or the left and right
arrow keys, to move through it. Press Escape or Close to return to the overview.

For a recording, use the player's play/pause control and timeline to seek. Captions
identify the demonstrated states.
