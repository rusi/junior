Your expert AI developer for Claude Code, Cursor, and Codex workflows

Junior is an expert AI software engineer, architect, and product development engineer for modern coding assistants. It's a trusted engineer who thinks deeply about architecture, challenges assumptions constructively, and writes production-quality code.

How to Install

Choose your environment to get the installation command.

Codex · macOS / Linux

Installation details
  • Codex: requires Python 3.11 or newer.
  • Project installs: trust the project in Codex to load its configuration.
  • Shared skills: Codex and Cursor use one installed skill version.
  • Cursor: global rules need separate setup.

Junior installs local files for your selected coding tool.

There is no default target. Always pass --target or -Target.

Open your project and start with jr-init.
